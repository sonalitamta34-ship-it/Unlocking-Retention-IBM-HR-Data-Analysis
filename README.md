# Unlocking Retention: A Data-Driven Behavioral Analysis of Employee Attrition

This project explores organizational psychology and industrial dynamics using the **IBM HR Analytics Employee Attrition & Performance** dataset. It aims to diagnose core turnover drivers and deliver actionable, executive-level recommendations to help HR leadership minimize costly employee churn.

## Core Analytical Frameworks
The analysis targets turnover risk profiles through five distinct corporate pillars:
* **Overtime Impact:** Evaluating how prolonged excess working hours correlate directly with resignation rates.
* **Income Equity:** Investigating systemic compensation variance and pay gaps across job roles.
* **Managerial Relationships:** Measuring the statistical impact of manager stability on team retention.
* **Role-Specific Demographic Risks:** Highlighting high-exposure zones across age brackets and department roles.
* **Work-Life Balance:** Correlating satisfaction scores with employee behavioral outcomes.

## Project Execution Steps
1. **Library Imports & Setup:** Establishing the data environment using Python (pandas, numpy, seaborn, matplotlib).
2. **Dataset Ingestion & Inspection:** Ensuring accurate data typing and validating structural bounds.
3. **Exploratory Data Analysis (EDA):** Visualizing asymmetric feature distributions and structural target class imbalances.
4. **Hypothesis Testing:** Executing strict statistical significance tests to separate true signals from noise.
5. **Strategy & Conclusion:** Synthesizing analytical findings into workforce intervention plans for stakeholders.
